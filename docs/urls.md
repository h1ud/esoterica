# URLs de prueba (REST)

Base: `http://localhost:8080`

## Productos
- **GET** `http://localhost:8080/api/products`
- **GET** `http://localhost:8080/api/products/1`
- **GET** `http://localhost:8080/api/products/search?name=Test`
- **POST** `http://localhost:8080/api/products`
- **PUT** `http://localhost:8080/api/products/1`
- **DELETE** `http://localhost:8080/api/products/1`

## Usuarios
- **GET** `http://localhost:8080/api/username`
- **GET** `http://localhost:8080/api/username/1`
- **POST** `http://localhost:8080/api/username`
- **PUT** `http://localhost:8080/api/username/1`
- **DELETE** `http://localhost:8080/api/username/1`
